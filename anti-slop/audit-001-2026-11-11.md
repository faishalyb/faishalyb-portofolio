# antislop audit 001 · 2026-11-11

- **Scope:** the portfolio site in this repository (home page, four case study pages, 404), before the revamp.
- **Filter:** antislop core 3.2.28, mode After.
- **How it was checked:** source read and searched; pages measured in the browser at 375 x 812 in light and dark themes (computed contrast of 226 text elements, control sizes, heading order, overflow).
- **Priority:** Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks = LOW.
- **Owner's decision:** fix all findings; keep the current visual direction (see `DESIGN.md`).

## Checked and passing

- **R-03 overflow:** no horizontal overflow at 375 px on the home page.
- **R-16:** no marketing buzzwords in the copy.
- **R-18, R-28, R-36:** no testimonials, no FAQ, no security or compliance claims.
- **R-21:** the theme follows the system setting and has a working toggle.
- **R-24:** the three navigation links point to sections that exist.
- **R-32:** a visible focus ring is defined and nothing removes outlines.
- **R-33:** no patch scripts in the repository.
- **R-39 (document):** `lang`, a unique title, landmarks, one `h1`, no skipped heading levels.
- **R-40:** content images carry width and height; no third-party scripts.
